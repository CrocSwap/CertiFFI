For the memset routine in memory.elf (sha256 2b73bba9...), at its reviewed address 0x1c8 (the 7 reviewed instruction words at 0x1c8-0x1e4), entered with the destination d in x0, the fill value in x1, the length n in x2 and a canonical return address in x30: the routine runs exactly 4n+3 model steps (2 if n = 0) and returns to the caller with x0 = d, every destination byte d+i (i < n) equal to the low byte of the fill value, every physical byte outside the destination's mapped bytes unchanged, and x4-x30, SP_EL0, the SIMD/FP registers, FPCR and FPSR preserved; for a caller destination that does not wrap. This holds over the canonical GB10 configuration source, on standard GB10 Linux, with no debugger, tracer or hardware profiler attached to the process, for every admissible configuration completion (including MTE2 present or absent), under the premises in the ratified manifest 1d66f3fb. The theorems assume memory.elf is started by ordinary execve and that, after startup, the reviewed routine is in memory exactly as reviewed (the loader-image obligations in the manifest, attested only at deployment). Generic-timer state is per-entry data, and the timers are assumed quiet over the execution window (GB10.TimersQuiet). The model is single-core: no other thread, device or DMA writes either buffer during the call. The theorems assume the memory system returns status OK for the routine's tag reads (PhysMemTagRead, Sail choice site 1354), an unattested hardware obligation (claim condition). The rest of memory.elf and the rest of the process are not verified. Every premise set is shown jointly satisfiable at every admissible completion (positive C2). The constant-time results additionally assume, as a caller contract, that the return address in x30 is outside the routine's code. Constant time (CT0, security grades v2.1) here means that two executions on the same deployment (address mapping, page tables, load base and reviewed image) whose public inputs (d, n and the return address) agree run to the return with equal model event records, and every event of every step of both runs has a record; the fill value is secret. The event records are the model's explicit accesses by virtual address and size, fetch and table-walk traffic by physical address and size, translation markers and ISB, with no data values; this is a property of the Arm architecture model and says nothing about caches, TLBs or prefetchers. Non-vacuity: a pair of admissible runs with different secrets is exhibited (fill 0x5a vs 0xa5; witness CT1Witness.Memset.memset_ct0ret_witness, statement sha256 c2d2c9cc4ef92489511e1198f4226e95e9510eb37a01a06f98a7a099f6c8f255), with every premise proved. Here 'statement sha256' is the SHA-256 of the witness theorem's statement as printed (pp.all) by the release gate and pinned in the release policy. Data-independent timing (CT1, security grades v2.1), for callers that enter with PSTATE.DIT = 1; no such caller is in the reviewed image: in addition to CT0, DIT = 1 holds at every body step, every executed instruction word is bound to the reviewed image word at its PC and is a DIT-listed instruction or public control, and no SVE/SME instruction is on the path (a pair of admissible runs with different fill values, entered with DIT = 1, is exhibited; witness CT1Witness.MemsetDit.memset_ct1ret_witness, statement sha256 9e9ab45ef7d792e69698b0755aaab615339220ca4d91bb997229da3fa625d8e7). Hardware timing then follows only under Arm's DIT timing contract (claim condition P3), which is neither proved nor measured; load/store data latency is excluded unless the instruction is DIT-listed, and addresses are covered by CT0. No secret residue at return, up to CT2.R3 (distinct-secret witness: fill 0x5a vs 0xa5; witness CT1Witness.Memset.memset_ct2ret_witness, statement sha256 db8ed59f2baa0a432c188b6ab7442965187bfe38f60264398737add0fa933b21): every general-purpose register is public or returned unchanged per run (x1 is the caller's own 64-bit fill value, of which only x1[7:0] is stored); NZCV is returned unchanged; every byte outside the destination is returned unchanged, and the destination is the declared secret output; V0–V31 and FPSR are returned unchanged. CT2.R4 (full SVE state) is not graded. Speculative-execution side channels, including straight-line speculation (SLS), are not addressed: the image is not built with SLS hardening, and no speculation property is claimed. All CT grades are about the architectural (Sail) semantics.
