For the memmove routine in memory.elf (sha256 2b73bba9...), at its reviewed address 0x1e4 (the 21 reviewed instruction words at 0x1e4-0x238), entered with the destination d in x0, the source s in x1, the length n in x2 and a canonical return address in x30: the routine runs exactly the number of model steps of its public path (2 if n = 0; 4 if d = s; 6n+6 copying forward if d < s; 6n+7 copying backward otherwise) and returns to the caller with x0 = d, every destination byte d+i (i < n) equal to the source byte s+i at entry, even when the buffers overlap, every physical byte outside the destination's mapped bytes unchanged, and x6-x30, SP_EL0, the SIMD/FP registers, FPCR and FPSR preserved; for caller buffers that do not wrap and whose source bytes are present. This holds over the canonical GB10 configuration source, on standard GB10 Linux, with no debugger, tracer or hardware profiler attached to the process, for every admissible configuration completion (including MTE2 present or absent), under the premises in the ratified manifest 3aaa4ffb. The theorems assume memory.elf is started by ordinary execve and that, after startup, the reviewed routine is in memory exactly as reviewed (the loader-image obligations in the manifest, attested only at deployment). Generic-timer state is per-entry data, and the timers are assumed quiet over the execution window (GB10.TimersQuiet). The model is single-core: no other thread, device or DMA writes either buffer during the call. The theorems assume the memory system returns status OK for the routine's tag reads (PhysMemTagRead, Sail choice site 1354), an unattested hardware obligation (claim condition). The rest of memory.elf and the rest of the process are not verified. Every premise set is shown jointly satisfiable at every admissible completion (positive C2). The constant-time results additionally assume, as a caller contract, that the return address in x30 is outside the routine's code. Constant time (CT0, security grades v2.1) here means that two executions on the same deployment (address mapping, page tables, load base and reviewed image) whose public inputs (d, s, n and the return address, which fix the path) agree run to the return with equal model event records, and every event of every step of both runs has a record; the copied bytes are secret. The event records are the model's explicit accesses by virtual address and size, fetch and table-walk traffic by physical address and size, translation markers and ISB, with no data values; this is a property of the Arm architecture model and says nothing about caches, TLBs or prefetchers. Non-vacuity: a pair of admissible runs with different secrets is exhibited (n = 1, source byte 0x5a vs 0xa5, backward path; witness CT1Witness.Memmove.memmove_ct0ret_witness, statement sha256 6dca394fda354f67d0254a71375105fd629df2cb9041fa0fe17434d43cb83301), with every premise proved. Here 'statement sha256' is the SHA-256 of the witness theorem's statement as printed (pp.all) by the release gate and pinned in the release policy. Data-independent timing (CT1, security grades v2.1), for callers that enter with PSTATE.DIT = 1; no such caller is in the reviewed image: in addition to CT0, DIT = 1 holds at every body step, every executed instruction word is bound to the reviewed image word at its PC and is a DIT-listed instruction or public control, and no SVE/SME instruction is on the path (identical-run non-vacuity only: the only proved instance of the CT1 premises is a pair of identical runs). Hardware timing then follows only under Arm's DIT timing contract (claim condition P3), which is neither proved nor measured; load/store data latency is excluded unless the instruction is DIT-listed, and addresses are covered by CT0. Secret residue (CT2.R0): FAIL. For n > 0, x4 (forward path, d < s) or x5 (backward path, d > s) is not proved equal across runs at return; it depends on the copied source data. Clearing it is the caller's responsibility. Speculative-execution side channels, including straight-line speculation (SLS), are not addressed: the image is not built with SLS hardening, and no speculation property is claimed. All CT grades are about the architectural (Sail) semantics.
